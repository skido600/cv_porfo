# Leo Wave Portfolio (cvformart)

## Overview

This is a personal portfolio site for Ebisi Chinecherem Leonard, also known as Leo Wave. It brings together his background, featured projects, work experience, and contact links in one clean, fast-loading page. The goal is to give recruiters, clients, and collaborators a clear picture of who he is and what he can build.

## Features

- **SEO-ready out of the box**: Rich metadata, Open Graph, Twitter cards, and a strong keyword set help the site rank and share well.
- **Single-page layout**: Top profile, about, work, experience, and contact sections all live on one smooth page.
- **Responsive design**: The layout adapts cleanly from mobile to desktop.
- **Type-safe code**: Written in TypeScript for fewer runtime surprises and easier maintenance.
- **Modern component architecture**: Each section is split into focused, reusable components.
- **Direct contact CTA**: A Gmail compose link makes it easy for visitors to reach out.

## Usage

Clone the repository, install dependencies, then start the local development server:

```bash
pnpm dev
```

Open your browser at `http://localhost:3000` to view the portfolio.

To build for production:

```bash
pnpm build
```

To start the production build:

```bash
pnpm start
```

To run the linter:

```bash
pnpm lint
```
